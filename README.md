# Luno Health

Medical travel to India. Written for families flying from Tashkent, Dushanbe and Almaty — Russian on every case.

## Run locally

```
python -m http.server 8765 --bind 127.0.0.1
```

Open http://127.0.0.1:8765/

## Replace later

- Phone / WhatsApp `+91 99999 99999`
- Email `care@lunohealth.com`
- Form endpoint in `assets/js/main.js`
- Medical-visa registration number (About + Terms)
